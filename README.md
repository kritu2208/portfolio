# Kritu Rajput — Portfolio

A cinematic, OTT-inspired personal portfolio showcasing my journey, data analysis projects, and technical skills as a **Data Analyst & AI Automation Specialist**.

---

## ✨ Features

- **Cinematic Experience:** Immersive streaming-platform aesthetic with interactive rails, project spotlights, and smooth transitions.
- **Project Showcases:** Interactive deep-dives into end-to-end data pipelines, predictive models, and analytics dashboards.
- **Data & Credentials:** Experience timeline, live certification badges (Coursera, Oracle, HarvardX), and an in-browser resume viewer.
- **Fully Responsive & Accessible:** Optimized for performance across mobile, tablet, and desktop with reduced-motion support.

---

## 🛠️ Tech Stack

- **Frontend:** React 18, TypeScript, Vite
- **Styling & Motion:** Tailwind CSS, Framer Motion, Lenis Smooth Scroll
- **Deployment:** Vercel

---

## 🚀 Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/kritu2208/portfolio.git

# Navigate to the project directory
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
